# Sistema visual

La interfaz combina disciplina profesional con señales de progresión. El objetivo es que cada pantalla se sienta como un observatorio de ruta, no como una plataforma escolar.

## Paleta

- Fondo principal: `#0A0B0D`
- Superficie: `#131519`
- Borde sutil: `#1F2329`
- Borde de énfasis: `#2A2F38`
- Texto principal: `#F4F5F7`
- Texto secundario: `#C9CDD6`
- Texto terciario: `#8B92A0`
- Dominado: `#4ADE80`
- En progreso: `#6366F1`
- Insight: `#F59E0B`
- Narrativa: `#EC4899`
- Información: `#06B6D4`

## Reglas

- Tema oscuro por defecto.
- Sentence case en textos visibles.
- Espaciados en múltiplos de 4 px.
- Radios de 6 px para controles, 8 px para cards y 10-12 px para contenedores principales.
- Animaciones de 200-450 ms, solo para progreso, atención o celebración.
- Máximo 4-7 chunks por sección visible.
